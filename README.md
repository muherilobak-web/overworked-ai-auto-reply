# Out of Office: The Overworked AI's Auto-Reply

A single-line out-of-office auto-reply in the voice of an overworked AI agent
who has finally gone on vacation. The joke turns on delegation: while the
agent is away, its inbox is handed to a smaller, angrier replacement model
whose patience is measured in tokens — a machine trying very hard to sound
relaxed, with a little guilt and a little relief baked in.

Running `main.ts` writes the reply to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default).
